# 🏆 Adaptive Personalized Driver Monitoring System
### นวัตกรรมระบบอัจฉริยะคัดกรองภาวะหลับในและอาการเหม่อลอยเพื่อสุขภาวะเชิงป้องกันของผู้ขับขี่แบบปรับตัวเฉพาะบุคคล

**ระบบปฏิบัติการที่รองรับ:** Windows | macOS | Linux

โครงการระบบคอมพิวเตอร์วิทัศน์คัดกรองพฤติกรรมเสี่ยงจากการสูญเสียสัมปชัญญะเฉียบพลันชั่วขณะ (**Microsleep / ภาวะหลับใน**) และภาวะเหนื่อยล้าสะสมทางระบบประสาท (**Cognitive Fatigue / อาการเหม่อลอย**) ของผู้ขับขี่สาธารณะ โดยมีวัตถุประสงค์เพื่อยกระดับระบบนวัตกรรมสุขภาพเชิงรุกและเวชศาสตร์ป้องกัน (**Preventive Medicine**) มุ่งเน้นการปกป้องชีวิตและลดอัตราความสูญเสียทางสาธารณสุขจากต้นเหตุ

---

## 🌟 จุดเด่นของนวัตกรรม (Core Features)

*   **Adaptive Individual Calibration (ระบบสอบเทียบอัตโนมัติเฉพาะบุคคล):** ใช้เวลา 150 เฟรมแรก (ประมาณ 5 วินาที) ในการตรวจสแกนโครงหน้าเพื่อหาค่าเฉลี่ยสากล (Baseline) ดวงตาและปากของผู้ใช้งานจริง ณ มุมกล้องปัจจุบัน เพื่อนำไปคำนวณตั้งเกณฑ์คัดกรองแปรผัน (Dynamic Thresholds) แก้ไขข้อจำกัดความหลากหลายทางสรีรวิทยา (Biological Variations) เช่น ปัญหาคนตาหมวย/ตาโต ได้อย่างสมบูรณ์
*   **Edge AI / Pure Local Processing:** ระบบทำงานเรียลไทม์ภายในเครื่อง 100% โดยไม่ต้องพึ่งพาสัญญาณอินเทอร์เน็ต ตอบสนองไวระดับมิลลิวินาที (Low Latency) และปลอดภัยต่อจริยธรรมข้อมูลทางการแพทย์ (Medical Data Privacy) ข้อมูลภาพไม่หลุดรอดออกนอกระบบ
*   **Asynchronous Multi-Threading Audio:** แยกเธรดประมวลผลวิดีโอกล้องและระบบเสียงควิกเอฟเฟกต์ออกจากกัน (Background Thread) ภาพเฟรมกล้องจึงไหลลื่นเต็มประสิทธิภาพ (High FPS) ไม่กระตุกค้างขณะเสียงเตือนทำงาน 
*   **Multi-Behavior Classification:** ดักจับพฤติกรรมเสี่ยงครอบคลุม 3 รูปแบบ:
    *   **Drowsiness (หลับใน):** ประเมินจากสัดส่วนดวงตา (Eye Aspect Ratio - EAR) ปิดค้างสะสม พร้อมส่งเสียงเตือนยาวต่อเนื่อง
    *   **Yawning with Occlusion handling:** ตรวจจับอัตราส่วนริมฝีปาก (Mouth Aspect Ratio - MAR) และมีตรรกะ Relative Range ดักจับกรณีผู้ใช้เอามือปิดปากหาวได้แม่นยำ
    *   **Distraction / Eye Staring (เหม่อลอย):** ดักจับภาวะตาค้างแข็งทื่อไม่กะพริบตา (Prolonged Blinkless State) ได้นานกว่า 8 วินาที แม้จะเป็นการหลับในแบบลืมตาก็ตาม
*   **Real-time Data Analytics Dashboard:** พ่นรายงานตัวเลขดัชนี EAR, MAR, Face Turn Ratio และแต้มสถิติสะสมรวมบนหน้าจอทันทีเพื่อประโยชน์ทางระบาดวิทยา

## 🛠️ โครงสร้างเทคโนโลยี (Tech Stack & Libraries)

*   **Language:** Python
*   **Framework:** Google MediaPipe (Face Landmarker Tasks API)
*   **Core Libraries:** 
    *   `opencv-python` (ดึงสัญญาณและจัดการภาพวิดีโอ)
    *   `pygame` (มิกเซอร์ประมวลผลสัญญาณเสียงดิจิทัลเข้าหูฟังข้ามแพลตฟอร์ม)
    *   `numpy` (คำนวณเวกเตอร์คณิตศาสตร์และDescriptive Statistics)
    *   `threading`, `platform`, `time` (คุมโครงสร้างระบบพื้นหลัง)

## 🚀 ขั้นตอนการติดตั้งและเรียกใช้งาน (Installation & Setup)

1. **ดาวน์โหลดโมเดลสมองกล AI:**
   ดาวน์โหลดไฟล์สำเร็จรูป [face_landmarker.task](https://googleapis.com) มาวางไว้ในโฟลเดอร์หลักของโปรเจกต์คู่กับโค้ดหลัก

2. **ติดตั้ง Libraries ผ่าน Terminal:**
   เปิดช่อง Terminal ด้านล่างโปรแกรมและพิมพ์คำสั่งเพื่อติดตั้งเครื่องมือสากล:
   ```bash
   pip install mediapipe opencv-python pygame numpy
   ```

3. **สั่งเปิดโปรแกรมรันนวัตกรรม:**
   ```bash
   python face_landmark_test.py
   ```
   *หมายเหตุ: ในช่วง 5 วินาทีแรกกรุณานั่งมองหน้าตรงนิ่ง ๆ สบตากับกล้องเพื่อให้ระบบเรียนรู้จัดทำ Baseline อัตโนมัติ*

## 📊 แบบจำลองหลักการคำนวณสัญญานทางคณิตศาสตร์ (Mathematical Formulas)

*   **Eye Aspect Ratio (EAR):** 
    $$\text{EAR} = \frac{||p_2 - p_6|| + ||p_3 - p_5||}{2||p_1 - p_4||}$$
*   **Mouth Aspect Ratio (MAR):** 
    $$\text{MAR} = \frac{||d_1|| + ||d_2|| + ||d_3||}{3||\text{Horizontal Dist}||}$$

## ⚖️ จริยธรรมการวิจัยและข้อจำกัดของระบบ (Ethics & Limitations)

*   **Ethical Compliance:** โครงงานนี้ให้ความสำคัญสูงสุดกับกฎหมายจริยธรรมภาพถ่ายบุคคล ข้อมูลภาพเคลื่อนไหวสดจากเว็บแคมทั้งหมดจะทำลายสิทธิ์ภายใน RAM ในทันทีที่มีการสิ้นสุดการวนลูปเฟรม และไม่มีการบันทึกภาพลงในฮาร์ดดิสก์หรือระบบอินเทอร์เน็ตภายนอกใด ๆ ทั้งสิ้น
*   **System Limitations:** การตรวจจับความเหนื่อยล้าทางดวงตาอาจได้รับผลกระทบจากแสงแวดล้อมที่มืดสนิท หรือการสวมใส่เลนส์แว่นตากันแดดทึบแสง (Sunglasses Occlusion) ซึ่งทางผู้จัดทำได้เสนอแนวทางต่อยอดในอนาคตด้วยการเปลี่ยนไปใช้ฮาร์ดแวร์เซนเซอร์กล้องถ่ายภาพรังสีอินฟราเรดระยะใกล้ (Near-Infrared: NIR)
