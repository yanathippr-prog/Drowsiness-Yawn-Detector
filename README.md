# 🚗 ระบบตรวจจับการง่วงนอนและการหาวเพื่อความปลอดภัยในการขับขี่ 
### (Real-time Computer Vision System for Microsleep Preventive Screening)

โปรเจกต์นี้เป็นระบบโครงงานพัฒนาเทคโนโลยีคอมพิวเตอร์วิทัศน์ (Computer Vision) แบบเรียลไทม์ เพื่อช่วยตรวจจับและคัดกรองพฤติกรรมการหลับใน (Microsleep) รวมถึงอาการเหนื่อยล้าของผู้ขับขี่จากการหาว เพื่อช่วยลดความเสี่ยงในการเกิดอุบัติเหตุบนท้องถนน

---

## ✨ คุณสมบัติของระบบ (Key Features)
- **Real-time Detection:** ตรวจจับใบหน้าและประมวลผลอาการง่วงนอนผ่านกล้องวิดีโอแบบเรียลไทม์
- **Drowsiness Screening:** ตรวจวัดอัตราการเปิด-ปิดตา เพื่อวิเคราะห์ภาวะการหลับในหรือสายตาล้า
- **Yawn Detection:** ตรวจจับพฤติกรรมการอ้าปากหาวที่เป็นสัญญาณเตือนขั้นแรกของความเหนื่อยล้า
- **Alert System:** ระบบเสียงสัญญาณเตือนภัยทันทีเมื่อตรวจพบสภาวะอันตรายของผู้ขับขี่

## 🛠️ เทคโนโลยีและเครื่องมือที่ใช้ (Technologies)
- **Language:** Python
- **Libraries & Frameworks:** 
  - OpenCV (สำหรับจัดการและประมวลผลวิดีโอจากกล้อง)
  - MediaPipe / Face Landmarker (เทคโนโลยีของ Google สำหรับตรวจจับจุดพิกัดสำคัญบนใบหน้าแบบ 3 มิติได้อย่างแม่นยำ)
- **Development Tools:** VS Code, Git & GitHub

## 📁 โครงสร้างไฟล์ในโปรเจกต์ (Project Structure)
- `app.py`: ไฟล์หลักสำหรับรันโปรแกรมระบบตรวจจับง่วงนอนและการหาว
- `face_landmark_test.py` / `beep_test.py`: ไฟล์ส่วนทดสอบระบบตรวจจับจุดบนใบหน้าและระบบทดสอบเสียงเตือน
- `face_landmarker.task`: ไฟล์โมเดล AI สำหรับตรวจหาพิกัดจุดเด่นบนใบหน้า
